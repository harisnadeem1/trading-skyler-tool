# Structure Milestone: Setups, Volume, and Execution

## Why this matters

This checkpoint closes the Intermediate level. It tests whether you can recognize both parent setups, map key levels, read volume, align timeframes, and execute without chasing.

## Clear explanation

This checkpoint tests application, not memory. Work without future candles, outside opinions, or hindsight.

A 30-minute trigger is valid only after the higher-timeframe setup is complete. Speed does not repair weak structure.

### Required chart work

Complete the following before the milestone quiz:

1. Annotate twenty Flat Base examples: ten valid and ten rejected.
2. Annotate twenty Controlled Pullbacks: ten valid and ten rejected.
3. Map pivot, support, invalidation, daily 8 EMA, 21 EMA, weekly 8 EMA, 50 EMA, and 200 SMA where relevant.
4. Record volume expansion, contraction, and confirmation.
5. Replay ten 30-minute triggers and calculate Low-of-Day ATR distance.
6. Document five trades you correctly rejected because the entry became late.

### Blind classification test

Use twenty unlabeled historical charts. For each, write:

- market context
- leadership evidence
- parent setup or no setup
- key level
- volume condition
- required trigger
- maximum acceptable entry
- disqualifying evidence

Do not reveal the next candles until every decision is recorded.

## Real example or short trading story

You receive several charts with future candles hidden. For each one, you must classify the parent setup, mark the pivot or support zone, choose the correct 30-minute trigger, and calculate entry efficiency.

A good explanation matters more than guessing which chart later rallied.

You pass this checkpoint when you can reject incomplete structures as confidently as you can recognize valid ones.

## Key rules / steps

1. **Classify each chart as Flat Base Breakout, Controlled Pullback, Developing, or No Setup.**
2. **Mark the pivot or support zone and structural invalidation.**
3. **Choose a valid 30-minute trigger only after the daily setup is complete.**
4. **Calculate Low-of-Day ATR and entry-to-stop ATR where relevant.**
5. **Reject incomplete or extended entries without using future candles.**

**Rule to remember**

> Structure earns attention. Confirmation earns execution. Efficiency determines whether the valid idea still offers a valid entry.

## Common mistakes

- Naming a setup without marking the level and invalidation
- Choosing a trigger before the daily structure is complete
- Ignoring Low-of-Day and entry-to-stop efficiency
